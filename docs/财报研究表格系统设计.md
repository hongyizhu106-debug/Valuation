# 财报研究表格系统设计

目标：把 10-K / 10-Q 从“原始 HTML”变成“可研究、可核对、可建模”的结构化表格系统。

## 1. 设计原则

1. 原文优先：每一条摘录都要尽量保留来源位置、来源表格或来源段落。
2. 事实和判断分开：财报披露的数据、管理层指引、系统计算的指标、分析结论不能混在一个字段里。
3. 可回溯：任何数字都要能回到 SEC filing、XBRL concept、表格标题或段落。
4. 不强行标准化：业务分部、产品线、地区口径每家公司不同，先保存公司原始口径，再做映射。
5. 标记置信度：XBRL 标准标签置信度高；HTML 表格解析中等；文本抽取的管理层指引需要低/中/高置信度。

## 2. 一级表格结构

### A. 公司与文件元数据表 company_filing_profile

用途：确认研究对象和文件身份。

字段：

- company_name
- ticker
- cik
- form_type
- filing_date
- report_period_end
- fiscal_year
- fiscal_quarter
- accession_number
- primary_document_url
- local_document_path
- auditor
- exchange
- sic / industry
- fiscal_year_end

### B. 核心财务三表 financial_statement_facts

用途：建立估值和健康诊断的基础数字。

字段：

- statement_type：income_statement / balance_sheet / cash_flow
- category
- metric_name
- xbrl_concept
- value
- unit
- period_start
- period_end
- duration_days
- accession_number
- confidence
- source_type：xbrl_companyfacts / filing_xbrl / html_table

重点指标：

- Revenue
- Gross profit
- Operating income
- Net income
- Diluted EPS
- Cash and equivalents
- Total assets
- Total liabilities
- Equity
- Current assets
- Current liabilities
- Operating cash flow
- Capital expenditure
- Free cash flow
- Debt
- Interest expense
- Share count

### C. 财务比率与健康诊断 financial_ratios

用途：从原始财务数据变成可比较指标。

字段：

- ratio_category：growth / profitability / cash_flow / liquidity / solvency / efficiency / valuation
- ratio_name
- formula
- value
- unit
- period
- interpretation
- warning_flag
- confidence

重点比率：

- revenue_growth
- gross_margin
- operating_margin
- net_margin
- operating_cash_flow_to_net_income
- free_cash_flow_margin
- current_ratio
- quick_ratio
- debt_to_equity
- debt_to_assets
- interest_coverage
- asset_turnover
- receivables_growth_vs_revenue_growth
- inventory_growth_vs_revenue_growth

### D. 业务分部表 business_segments

用途：回答“公司到底靠什么赚钱”。这是非财务研究的核心表。

字段：

- segment_name
- segment_type：product / service / geography / customer / channel
- revenue
- revenue_yoy_growth
- operating_income
- operating_margin
- assets
- capex
- depreciation_amortization
- cash_flow_if_disclosed
- share_of_total_revenue
- share_of_total_operating_income
- period
- source_table_title
- source_section
- confidence

注意：很多公司不会披露“每个业务的现金流”。这种情况下：

- 如果披露 segment operating income，就用 operating income 作为经营贡献指标。
- 如果披露 segment assets / capex / D&A，可以近似分析资本强度。
- 不要把公司总现金流硬拆到各业务，除非披露或有明确合理分摊假设。

### E. 客户结构 customer_mix

用途：判断收入质量、集中度和外部风险。地区维度暂不做。

字段：

- dimension：customer / product / channel
- item_name
- revenue
- revenue_share
- yoy_growth
- risk_note
- source_section
- confidence

重点摘录：

- Top customer concentration
- Government / enterprise / consumer mix
- Subscription / license / hardware / services mix

### F. 管理层指引 guidance_outlook

用途：把“下一年预期”从文字里抽出来，服务 DCF 假设。

字段：

- guidance_period：next_quarter / next_year / fiscal_year / long_term
- metric：revenue / gross_margin / operating_expense / capex / tax_rate / EPS / FCF
- guidance_type：point / range / qualitative
- low_value
- high_value
- midpoint
- unit
- quoted_text
- source_document：10-K / 10-Q / earnings_release / 8-K / earnings_call / investor_presentation
- source_section
- confidence

注意：10-K / 10-Q 不一定有明确“明年收入指引”。更常见来源是 earnings release、8-K、earnings call transcript、investor presentation。系统应该允许后续接入这些来源。

### G. 管理层讨论与经营驱动 mdna_drivers

用途：解释数字为什么变化。

字段：

- driver_category：price / volume / mix / FX / acquisition / divestiture / cost / demand / supply_chain
- affected_metric
- direction：positive / negative / mixed
- magnitude_if_disclosed
- quoted_text
- normalized_summary
- source_section
- confidence

### H. 风险因素 risk_factors

用途：识别业务和财务风险。

字段：

- risk_category：market / competition / regulation / supply_chain / customer_concentration / technology / litigation / accounting / liquidity
- risk_title
- quoted_text
- potential_financial_impact
- affected_segments
- source_section
- confidence

### I. 会计质量与红旗 accounting_quality_flags

用途：判断财报健康程度和数字可信度。

字段：

- flag_type
- severity：low / medium / high
- evidence
- affected_metric
- source_section
- suggested_check

常见红旗：

- 收入增长明显高于经营现金流增长
- 应收账款增长高于收入增长
- 存货增长高于销售增长
- 非 GAAP 调整长期过大
- 重组费用反复出现
- 商誉和无形资产占权益比例过高
- 审计意见或内控缺陷

### J. 估值输入 assumptions_for_valuation

用途：把研究结果转成 DCF / comps 模型输入。

字段：

- assumption_name
- base_case
- bear_case
- bull_case
- unit
- source
- rationale
- confidence

重点假设：

- revenue_growth_by_segment
- gross_margin
- operating_margin
- tax_rate
- D&A
- capex
- working_capital_need
- terminal_growth
- WACC
- exit_multiple

## 3. 页面展示建议

控制面板右侧从上到下显示：

1. 公司和文件摘要
2. 财务三表关键数据
3. 自动计算比率
4. 业务分部收入/利润/资本强度
5. 客户/产品/渠道结构
6. 管理层指引与明年预期
7. MD&A 经营驱动
8. 风险因素和会计红旗
9. SEC 原文预览

每一张表都应该有：

- 导出 CSV
- 复制表格
- 查看来源
- 置信度标签
- 缺失数据提示

## 4. 实现优先级

### Phase 1：已实现/正在实现

- SEC filing 下载
- 原始 HTML 预览
- XBRL 核心财务数据摘录
- 文件元数据表

### Phase 2：下一步最该做

- 财务比率自动计算
- 业务分部表：从 XBRL / HTML table 里抽 revenue、operating income、assets
- CSV 导出

### Phase 3：研究增强

- MD&A 文本抽取
- 风险因素摘录
- 管理层指引抽取
- 8-K / earnings release / earnings call 来源接入

### Phase 4：估值模型

- revenue growth by segment
- margin forecast
- FCF forecast
- WACC
- terminal value
- sensitivity table
- implied share price

## 5. 数据来源策略

优先级：

1. SEC XBRL companyfacts：适合标准财务指标，稳定、可追踪。
2. Filing inline XBRL：适合当前报表的精确事实。
3. HTML 表格：适合分部、地区、产品线等非标准表格。
4. 文本段落：适合 MD&A、风险因素、管理层指引。
5. 8-K / earnings release / earnings call：适合下一季度/下一年指引。

## 6. 不应该做的事

- 不要把没有披露的分部现金流强行估算成事实。
- 不要把文字性乐观表述当成数值指引。
- 不要把公司财年季度和自然季度混淆。
- 不要忽略单位：百万、千、美元、股份、百分比。
- 不要把一次性项目和持续经营表现混在一起。
